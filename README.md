# TheoreCodeNotes

Полный конспект курса по теории помехоустойчивого кодирования (13 лекций), сверстанный в [Typst](https://typst.app/).

## Структура конспекта

Каждая лекция — отдельный файл-глава `chNN.typ`; все они подключаются в `main.typ`.

| Файл | Содержание |
|---|---|
| `ch-notat.typ` | «Обозначения и соглашения» — словарь всех используемых символов |
| `ch00.typ` | Системы передачи информации, основы теории кодирования, границы на параметры кодов |
| `ch01.typ` | Универсальные методы декодирования (МПС, решётки/Витерби, BCJR) |
| `ch02.typ` | Локально восстанавливаемые коды (LRC, коды Тамо—Барга, Windows Azure) |
| `ch03.typ` | Сверточные коды, алгоритм Витерби, производящие функции |
| `ch04.typ` | Модификации и комбинирование кодов (Плоткин, Рида—Маллера, каскадные, турбо) |
| `ch05.typ` | Полярные коды (поляризация, ПИ, списочное декодирование, подкоды) |
| `ch06.typ` | Циклические коды, БЧХ, коды Рида—Соломона, декодирование (ПГЦ, Форни, алгоритм Евклида) |
| `ch07.typ` | Альтернантные коды, коды Гоппы, криптосистема Мак-Элиса |
| `ch08.typ` | LDPC-коды (граф Таннера, РД/ЛОПП, эволюция плотностей, конструкции) |
| `ch09.typ` | Коды для стирающего канала (цифровой фонтан, LT, Raptor) |
| `ch10.typ` | Кодовая модуляция (БКМ, многоуровневые коды, шейпинг) |
| `ch11.typ` | Сетевое кодирование (потоки, разрезы, линейные сетевые коды) |
| `ch12.typ` | Регенерирующие коды (граница Димакиса, MSR/MBR, восстановление в кодах РС) |

`lib.typ` — стилевая библиотека: окружения теорем/лемм/определений/алгоритмов, инициализация документа, математические операторы.

## Сборка локально

Нужен [Typst](https://github.com/typst/typst) (использовался `typst 0.15.x`). Из корня репозитория:

```sh
typst compile main.typ out.pdf
```

Результат — `out.pdf` (~90 страниц). Сборка локальная, внешних зависимостей и шрифтовых пакетов не требует.

### Установка typst

- **macOS (Homebrew):** `brew install typst`
- **Linux:** `curl -fsSL https://typst.community/installer/install.sh | sh` либо скачать бинарник со страницы [релизов](https://github.com/typst/typst/releases)
- **Windows:** `winget install --id Typst.Typst`
- **Без установки:** веб-редактор [typst.app](https://typst.app) — можно залить исходники и собирать там.

## Инструкция для агентов (Claude/других LLM-ассистентов)

Если ты — ИИ-агент, которому поручили править или расширять этот конспект:

1. **Синтаксис Typst отличается от LaTeX.** Официальная документация: <https://typst.app/docs/> — держи её под рукой (особенно разделы *Scripting*, *Math*, *Reference*). Полезно: math-режим `$ ... $` (display) / `$ ... $ inline`; мультибуквенные идентификаторы в формулах нужно заключать в кавычки (`$"GRS"(...)`) или объявлять операторами (`#let diag = math.op("diag")`); `product` вместо `\prod`; `not in` вместо `notin`.
2. **Проверяй сборку после каждой правки:** `typst compile main.typ out.pdf` — компилятор с точностью до строки указывает на синтаксические ошибки. Частые грабли: незакрытые строки в math-режиме (`"текст"` без парной кавычки роняет весь файл), преждевременная `]`, закрывающая `#thm[...]` раньше времени, пустые ячейки в `mat(...)`.
3. **Дисциплина обозначений.** Каждый символ при первом употреблении вводится словами в тексте; общий словарь — в `ch-notat.typ` (при введении нового глобального обозначения добавляй его туда). Формулы — в display-стиле, с пояснением «где …» после каждой нетривиальной формулы.
4. **Не пересобирай главы заново без нужды** — правки делай точечными (`Edit`/`sed`), файлы глав самодостаточны и подключаются из `main.typ`.
